Case study

CareerPilot: turning job-search repetition into a product workflow.

CareerPilot started from a simple pain point: tailoring applications is repetitive, but fully automating the process too early creates trust and quality problems. I treated the first version as a control center, not a magic button.

Problem

Job seekers need faster resume tailoring without losing control over what gets sent to employers.

Constraints

The MVP needed to support uploads, provider sessions, and AI tailoring while staying deployable across separate frontend and backend hosts.

Decision

I split the product into a Next.js interface and Flask automation backend so UI changes could move quickly while heavier browser/session work stayed isolated.

Tradeoff

That split adds deployment coordination, but it keeps long-running automation and credential-sensitive flows away from the client app.

What I would revisit

If usage grew, I would add job-level evaluation metrics, queueing for slow tailoring tasks, and a clearer review layer before any application action.
