Personal software

A private assistant for my job search.

Career Ops helps me find suitable roles, prepare truthful tailored resumes, complete application forms, and keep an application history. It is operated by Ayomide Oduba for his own use and is not offered as a public service.

Why it connects to Gmail

Some application systems email a short verification code while an application is in progress. Career Ops requests read-only Gmail access so it can locate those messages in Ayomide Oduba's mailbox and read the required code.

It cannot send, edit, or delete email. Access is limited to the account that explicitly authorizes the app and can be revoked at any time from Google Account settings.
