Privacy Policy

Career Ops is a private job-search automation tool operated by Ayomide Oduba for his own use.

Google data the app accesses

Career Ops requests read-only access to the Gmail account that authorizes it. It searches for recent job-application verification messages, checks the sender, recipient, and arrival time, and reads the verification code needed to continue an application.

How the data is used

Gmail data is used only to retrieve verification codes for Ayomide Oduba's own job applications. Career Ops does not use Gmail data for advertising, profiling, analytics, or training artificial-intelligence models.

Storage and sharing

The OAuth token is stored in a restricted local file on Ayomide Oduba's private server. Verification codes are used during the active application and are redacted from logs. Career Ops does not sell or share Google user data with third parties.

Limited Use

Career Ops's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and deletion

The Gmail OAuth token remains until access is revoked or the token file is deleted. Verification codes are not intentionally retained. Access can be revoked through the Google Account third-party connections page. To request deletion of any Career Ops data, email the address below.

Security

Career Ops uses a read-only Gmail scope, restricts access to its server files, redacts secrets and verification codes from logs, and does not expose its operational dashboard to the public internet.

Contact

For privacy questions or deletion requests, email dubathedev@gmail.com.
